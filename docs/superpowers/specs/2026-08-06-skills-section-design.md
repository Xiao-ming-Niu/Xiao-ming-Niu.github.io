# 技能区块优化设计

- 日期：2026-08-06
- 状态：已确认（用户批准）
- 范围：个人主页 `_pages/zh.md` 的「🛠 技能」区块；英文版 `_pages/about.md` 及主页其它改动（兴趣爱好、研究列表）**稍后**一并同步。

## 目标

将技能区块从带 `[...]` 占位符的纯文本列表，优化为**分类文字列表**，只包含用户确认的真实技能，并与「算法工程师求职」目标对齐。

## 展示风格

分类文字列表（用户选定）。理由：学术主页风格、可信度高、无虚假精度。

## 最终内容

```markdown
# 🛠 技能

- **编程语言:** Python, MATLAB
- **机器学习 / 深度学习:** PyTorch, Scikit-learn
- **计算机视觉:** OpenCV
- **数学工具:** Mathematica
- **工具:** Git, LaTeX, Typst, Office
```

设计要点：

- MATLAB 仅出现在「编程语言」中（用户确认其为语言之一），避免与「数学工具」重复。
- PyTorch（深度学习）与 Scikit-learn（机器学习）合并为一类，避免单条目类别稀疏。
- 量子计算、有限元等属研究方向，不列入技能工具类别。

## 求职建议学习路线（不写入页面）

针对算法工程师岗位的后续学习优先级（学会并熟练后再写入技能栏）：

1. 数据结构与算法 / LeetCode —— 面试核心
2. C++ —— 多数算法岗硬性要求
3. Linux / Shell —— 日常开发环境
4. HuggingFace Transformers —— NLP 方向标配
5. ONNX / TensorRT / Docker —— 模型部署加分项

当前已接触并写入页面的推荐补充：OpenCV、Scikit-learn。
